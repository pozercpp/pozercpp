## Featured projects

### [Full-Text Search Engine](https://github.com/pozercpp/search_engine)

A C++20 search engine for local document collections with recursive indexing,
boolean queries, BM25 ranking, JSON index persistence, and an interactive CLI.
The project follows a layered architecture with separate tokenization,
indexing, ranking, query, and utility components.

`C++20` `CMake` `STL` `nlohmann/json` `BM25`

### [POSIX FIFO Messenger](https://github.com/pozercpp/MESSENGER)

A client-server messaging system built around POSIX named pipes. It supports
authentication, direct messages, delayed delivery, and store-and-forward for
offline users, with shared state synchronized using POSIX mutexes.

`C++20` `POSIX FIFO` `pthreads` `Linux` `CMake`
